# PROFIT Loyalty Ecosystem 🪙

Ласкаво просимо до репозиторію **PROFIT** — сучасної, гейміфікованої екосистеми лояльності з єдиною внутрішньою валютою (токени **MD**), інтерактивною картою партнерів, Колесом Удачі та гнучкою системою рівнів (Silver, Gold, Platinum, Diamond).

Проект складається з двох основних частин:
1. **Бекенд (Backend)**: Реактивний REST API на FastAPI, асинхронний SQLite (SQLAlchemy + aiosqlite), Pydantic v2 та JWT-авторизація.
2. **Фронтенд (Frontend)**: Високопродуктивний веб-додаток на Next.js 16 (React 19) з компіляцією Turbopack, Tailwind CSS v4 та стейт-менеджером Zustand.

## 🚀 Як швидко запустити проект локально

### 1. Запуск бекенду (API)
Перейдіть до папки `backend` та виконайте наступні команди:
```bash
# 1. Створення віртуального середовища
python -m venv .venv
call .venv\Scripts\activate

# 2. Встановлення залежностей
pip install -r requirements.txt

# 3. Запуск сервера розробки
# (Використовуйте bat файл для безпечного перезавантаження без циклічних блокувань SQLite)
run_dev.bat
```
*API буде доступний за адресою: `http://localhost:8000`. Інтерактивна документація (Swagger): `http://localhost:8000/docs`.*

### 2. Запуск фронтенду (Next.js)
Перейдіть до папки `frontend-main` та запустіть Turbopack:
```bash
# 1. Встановлення залежностей Node
npm install

# 2. Запуск у режимі розробки з Turbopack
npm run dev
```
*Клієнтський додаток відкриється за адресою: `http://localhost:3000`.*

## 🎨 Дизайн-система та Світла/Темна теми

Додаток PROFIT підтримує динамічне перемикання тем (світлої та темної).
* **Світла тема**: М'який кремовий фон (`#F9F5E8`), глибокий смарагдовий текст (`#102820`) та витончені золоті градієнти.
* **Темна тема** (За замовчуванням): Елегантні темно-зелені тони (`#0D1B18`), контрастні золотисті лінії та світлий текст (`#F9F5E8`).

Для перемикання використовується преміальна кнопка **`ThemeToggle`** (візуалізована у вигляді сонечка з повільною мікро-анімацією обертання в темному режимі та місяця в світлому). Перемикач інтегрований у:
- Головну навігаційну панель Landing Page.
- Сторінку авторизації `/auth` (плаваючий перемикач у правому верхньому кутку).
- Панель швидкого доступу Sidebar усередині кабінету користувача.

Конфігурація теми зберігається в `localStorage` клієнта під ключем `theme`. У `layout.tsx` вбудовано скрипт швидкої ініціалізації, що запобігає неприємному блиманню екрана при перезавантаженні сторінки.

## 🔒 Налаштування безпеки та Git (.gitignore)

Для захисту конфіденційних файлів при завантаженні на GitHub чи інші хостинги у корені проекту та відповідних директоріях налаштовано файли `.gitignore`. Вони ігнорують:
* Бази даних SQLite (`.db`, `.sqlite3`).
* Локальні файли конфігурацій середовища (`.env`, `.env.local`).
* Папки кешу компіляторів (`.next/`, `node_modules/`, `__pycache__/`, `.pytest_cache/`).
* Віртуальні оточення Python (`.venv/`, `env/`).
* Специфічні папки IDE (`.vscode/`, `.idea/`).
